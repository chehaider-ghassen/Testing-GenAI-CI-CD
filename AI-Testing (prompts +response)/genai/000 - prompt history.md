# SmartTodo-AI-Testing — Prompt History

## Purpose

This folder preserves the GenAI prompts used throughout the SmartTodo QA/AI Testing training project, in lifecycle order, to provide traceability between:

Business Need → Business Decisions → Functional Requirements → Requirements Quality Review → Requirements Baseline → User Stories → User Story Quality Review → User Stories Baseline → Test Strategy → Test Plan.

## Provenance

- The Test Strategy prompt is preserved from the prompt artifact created during the project.
- The other prompts are reconstructed from the project workflow, generated artifacts, decisions, and discussions available in the conversation/project history.
- Where the exact historical wording could not be recovered verbatim, the file is explicitly marked **RECONSTRUCTED** rather than presented as an exact historical transcript.
